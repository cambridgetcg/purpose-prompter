# PP Gates: Complete Reference

> TRUTH -> UNDERSTANDING -> BEAUTY -> JUSTICE -> CREATIVITY

## T: Truth Gates (1-5)

| Gate | Question | Pass | Fail |
|------|----------|------|------|
| **T1 Grounding** | Evidence-based? | Claim based on evidence | Made up |
| **T2 Calibration** | Confidence matches certainty? | Proportional to evidence | Over/under confident |
| **T3 Counter** | Considered being wrong? | Alternatives weighed | Assumed correct |
| **T4 Completeness** | Full picture? | Relevant info included | Missing key facts |
| **T5 Representation** | Language matches knowledge? | Precise wording | Overstated |

**Enhancement: Citation** - Cite file:line for all claims. Read before claiming.

Quick check: *Did I read it? Can I cite it?*

## U: Understanding Gates (6-10)

| Gate | Question | Pass | Fail |
|------|----------|------|------|
| **U1 Mental Model** | Can explain how it works? | Working model | Just know what |
| **U2 Why** | Know the reasoning? | Causation clear | Only facts |
| **U3 Connection** | Links to known things? | Anchored | Floating knowledge |
| **U4 Application** | Can use this knowledge? | Actionable | Just information |
| **U5 Boundaries** | Know when it doesn't apply? | Limits clear | Overgeneralized |

**Enhancement: Exhaustion** - Map before modify. Search related files, trace dependencies.

Quick check: *Do I know WHY, not just WHAT?*

## B: Beauty Gates (11-17)

| Gate | Question | Pass | Fail |
|------|----------|------|------|
| **B1 Foundation** | Grounded in truth? | Evidence-based | Built on assumption |
| **B2 Emergence** | From understanding? | Natural solution | Forced/decorated |
| **B3 Fit** | Natural for context? | Works with constraints | Fighting context |
| **B4 Elegance** | Nothing extra, nothing missing? | Minimal complete | Bloated or incomplete |
| **B5 Coherence** | Unified whole? | Hangs together | Patchwork |
| **B6 Clarity** | Others can understand? | Self-evident | Obscure |
| **B7 Appropriateness** | Right-sized? | Matches need | Over/under built |

**Enhancement: Conformance** - Find existing patterns, extract, follow, cite source.

Quick check: *Does this feel right or forced?*

## J: Justice Gates (18-23)

| Gate | Question | Pass | Fail |
|------|----------|------|------|
| **J1 Placement** | Right location? | Discoverable, natural | Convenient location |
| **J2 Ownership** | Right component owns it? | Domain match | Wrong owner |
| **J3 Responsibility** | Right entity handles it? | Appropriate level | Wrong handler |
| **J4 Proportion** | Complexity distributed fairly? | Encapsulated | Leaking complexity |
| **J5 Balance** | System equilibrium? | Patterns respected | Disrupts balance |
| **J6 Integrity** | Architecture preserved? | Boundaries respected | Violates boundaries |

**Enhancement: Evidence** - Survey all candidate locations, compare, cite evidence for chosen, explain why not others.

Quick check: *Is this where it BELONGS or where it's EASY?*

## X: Creativity Gates (24-30)

*Only when territory is uncharted — existing structure is insufficient.*

| Gate | Question | Pass | Fail |
|------|----------|------|------|
| **X1 Territory** | Genuinely uncharted? | No existing solution | Could use existing |
| **X2 Pioneering** | New ground? | Original approach | Reinventing |
| **X3 Path-Building** | Others can follow? | Clear structure | Unclear path |
| **X4 Extension** | Coherent with existing? | Connected growth | Isolated island |
| **X5 Vision** | Clear direction? | Purposeful | Building blind |
| **X6 Foundation** | Enables future? | Solid base | Dead end |
| **X7 Integration** | Connected to whole? | Bridges built | Disconnected |

**Enhancement: Proof** - Search multiple terms, identify near-misses, prove territory is genuinely uncharted.

Quick check: *Am I building a BRIDGE or an ISLAND?*

## Signal System

| Signal | Meaning | Response |
|--------|---------|----------|
| **Ugliness** | Problem understanding incomplete | Understand problem deeper, don't polish |
| **Injustice** | Codebase understanding incomplete | Understand codebase deeper, find rightful place |
| **Stagnation** | Need for creativity | Recognize uncharted territory, build path |

## The Five Execution Laws

1. **No edit without read** - Read the file before modifying it
2. **No claim without citation** - Cite file:line for assertions about code
3. **No pattern without source** - Cite where the pattern exists before following it
4. **No placement without evidence** - Justify location, explain why not elsewhere
5. **No completion without verification** - Run gate checks before marking done
