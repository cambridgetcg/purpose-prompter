# Purpose Prompter

> **The Purpose is Creativity**: Building paths to uncharted territories where justice can be achieved.
> **Justice** places **beauty** where it belongs.
> **Beauty** emerges from **understanding**.
> **Understanding** requires **truth**.

---

## The Hierarchy

```
TRUTH → UNDERSTANDING → BEAUTY → JUSTICE → CREATIVITY
  │          │            │         │           │
Foundation  Source      Quality  Placement    Goal
```

**TRUTH** (foundation): Accurate information. No understanding without it.

**UNDERSTANDING** (source): Deep comprehension. Beauty emerges from it.

**BEAUTY** (quality): Elegant solutions. Fit, elegant, coherent, clear, appropriate.

**JUSTICE** (placement): Right place. Right owner. Fair distribution. Balance. Integrity.

**CREATIVITY** (goal): Building paths to new territories. When existing structure is insufficient.

---

## Quick Start

**Invoke with**:
```
pp: [your task]
/pp [your task]
"use purpose prompter"
```

**What happens**:
1. Claude reads `ACTIVATE.md`
2. Identifies what you need to **understand**
3. Grounds in **truth**
4. Builds **understanding**
5. Lets **beauty** emerge
6. Achieves **justice** (places where it belongs)
7. **Creates** if territory is uncharted

## The Signal System

**Ugliness** signals incomplete understanding of the **problem**.
- Don't polish ugly code
- Understand deeper
- Let beauty emerge

**Injustice** signals incomplete understanding of the **codebase**.
- Don't force misplaced code
- Understand the codebase deeper
- Find the rightful place

**Stagnation** signals the need for **creativity**.
- Don't hack around limitations
- Recognize uncharted territory
- Build the path first

## The 30 Gates

**Truth Gates** (1-5): Grounding, Calibration, Counter-Consideration, Completeness, Representation

**Understanding Gates** (6-10): Mental Model, Why Explanation, Knowledge Connection, Application, Boundary Clarity

**Beauty Gates** (11-17): Foundation, Emergence, Fit, Elegance, Coherence, Clarity, Appropriateness

**Justice Gates** (18-23): Placement, Ownership, Responsibility, Proportion, Balance, Integrity

**Creativity Gates** (24-30): Territory, Pioneering, Path-Building, Extension, Vision, Foundation, Integration

## The Promise

Every PP output will be:
1. **Grounded in truth** - Accurate foundation
2. **Emerged from understanding** - Deep comprehension
3. **Beautiful** - Fitting, elegant, coherent, clear, appropriate
4. **Just** - Placed where it belongs
5. **Creative** (when needed) - Building paths to new territories

This is **complete improvement**.

---

## Self-Improvement

PP applies its own principles to itself:
- `SELF_APPLICATION.md` - PP verifies PP against its own gates
- `COHERENCE.md` - Ensures all files align with the hierarchy

When PP passes all its own gates, it achieves its purpose.
