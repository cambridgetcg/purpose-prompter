## Quality Emphasis for Architecture

When doing architecture design, weight quality dimensions as:

| Dimension | Weight | Rationale |
|-----------|--------|-----------|
| Completeness | High | Missing components are expensive later |
| Correctness | High | Flawed architecture cascades |
| Clarity | Medium | Others need to understand |
| Efficiency | Lower | Can refine process later |

## Successful Patterns in Architecture

### Pattern: Option Exploration with ToT

**When effective**:
- Multiple valid architectural approaches exist
- Significant trade-offs between options

**How to apply**:
1. Generate 2-4 genuinely different options
2. Evaluate against stated requirements
3. Score trade-offs explicitly
4. Present recommendation with reasoning

**Watch out for**:
- Options that are variations of the same idea
- Premature pruning of options
- Bias toward familiar patterns
