## Coherence Rules

### Rule 1: Every File References the Hierarchy

Every PP file should connect to the hierarchy:
```
TRUTH → UNDERSTANDING → BEAUTY → JUSTICE → CREATIVITY
```

**Check**: Does this file know its place in the hierarchy?

### Rule 2: No Contradictions

No file should contradict another file. If concepts have evolved, older files must be updated or removed.

**Check**: Does this file align with UNIFIED_MODEL.md?

### Rule 3: Single Source of Truth

Each concept should have one authoritative definition. Other files reference, don't redefine.

**Check**: Is this file authoritative or derivative? Is it clear?

### Rule 4: Complete Coverage

Every level of the hierarchy should have:
- Philosophy file (X.md)
- Verification file (X_VERIFICATION.md)
- Gates file (X_GATES.md)
- Feedback file (X_FEEDBACK.md)
- Patterns file (X_patterns.md)

**Check**: Is the hierarchy level fully covered?

### Rule 5: Demonstrative Structure

Files should demonstrate the hierarchy in their own structure, not just describe it.

**Check**: Does this file embody what it teaches?

## Coherence Restoration Protocol

### Phase 1: Handle Legacy Files

```
FOR each legacy file (PURPOSE*.md, purpose_*.md):
  1. Read the file
  2. Extract valuable unique content
  3. Determine if content belongs in current hierarchy
  4. If yes: Integrate into appropriate current file
  5. If no: Archive or remove
  6. Update any cross-references
```

### Phase 2: Update Application Files

```
FOR each application file (workflows/, patterns/, templates/):
  1. Read current content
  2. Identify references to old concepts
  3. Transform to use the hierarchy
  4. Verify integration with philosophy files
  5. Update cross-references
```

### Phase 3: Update README

```
1. Rewrite README to reflect:
   - The complete hierarchy
   - Current file structure
   - Proper invocation methods
   - The self-application capability
2. Make README itself beautiful (not just descriptive)
```

### Phase 4: Verify Coherence

```
FOR each file in PP:
  1. Run file coherence check
  2. Run cross-file coherence check
  3. Verify hierarchy references are correct
  4. Verify no contradictions remain
```
