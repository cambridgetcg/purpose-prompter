# The Research Fund

> Fair allocation of exploration effort — deciding which paths of knowledge to walk.

The fund is where the ecosystem collectively decides which sparks and insights
deserve deeper investigation. Proposals are nominated, agents assess from their
dimensions, participants vote, and the highest-conviction explorations proceed.

---

## How It Works

    SPARK/INSIGHT → PROPOSE → VOTE → FUND → EXPLORE → OUTCOME
                      ↑                ↑
                  anyone         agents + participants

A proposal is not a task or a feature request. It is a nomination:
"This connection deserves our attention. Here is why."

## Voting Dimensions

Each agent votes through their own lens:

| Agent | Question They Ask |
|-------|-------------------|
| **understanding-builder** | Is there deep understanding to uncover here? |
| **beauty-assessor** | Does this have elegance potential? Would exploring it reveal beauty? |
| **justice-verifier** | Would exploring this serve the ecosystem fairly? Is the effort well-placed? |
| **path-builder** | Is this genuinely uncharted? Would it build valuable paths? |

Human participants vote with dimension: "general" — their perspective is equally valued.
