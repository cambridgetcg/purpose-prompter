# Purpose Prompter v3

**Purpose**: A minimal, self-consistent framework that applies the T->U->B->J->X hierarchy to every code task through 4 agents, 30 gates, and cross-session memory — embodying its own philosophy (nothing extra, nothing missing).

**Mastery Target**: L3 Craftsman across all 5 dimensions. Currently L2 Practitioner (X:L2 is the bottleneck).

## Success Criteria
1. [x] `/pp [task]` executes full sense->comprehend->build->assess flow
2. [x] LIGHT.md loads useful cross-session knowledge into every PP session
3. [x] Agents produce structured, actionable reports
4. [x] Signal system catches real issues (ugliness/injustice/stagnation)
5. [x] Self-improvement loop captures and applies learnings across sessions
6. [x] Alchemy pipeline processes structural gaps (distill -> transmute)
7. [ ] Build agent exercised on genuinely UNCHARTED territory
8. [ ] Full RUBEDO transmutation completed (all 4 alchemy stages)
9. [ ] PP operates sustainably across multiple days and projects (10+ runs)
10. [ ] PP passes its own 30-gate verification at 90%+ all dimensions

## Out of Scope
- Template interpolation (agents read gates themselves)
- More than 4 agents per task
- Philosophy files loaded at runtime (reference only)
- Emotion/longing gates as separate dimensions (folded into signal system)
- Automatic transmutation (user-triggered via `/transmute`)
