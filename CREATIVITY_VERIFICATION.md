# Creativity Verification Protocol

> **Axiom**: Creativity is bringing justice to uncharted territories through building a path.
> Verification ensures that when creativity is needed, paths are properly built.
> Without creativity verification, we may be stuck or building paths to nowhere.

## Step 0: Territory Check (First)

### The Core Question
**Is this charted or uncharted territory?**

This determines whether creativity is needed or justice alone suffices.

### Verification Questions

```markdown
**Task**: [What I'm trying to accomplish]

**Territory Check**:
1. Does structure exist to place this solution? [Yes / No]
2. Are there established patterns for this type of work? [Yes / No]
3. Is there a "rightful place" for this in the current codebase? [Yes / No]
4. Can justice be achieved with existing structure? [Yes / No]

**If all Yes**: Territory is charted → Justice mode
**If any No**: Territory is uncharted → Creativity mode
```

### Charted vs. Uncharted

| Charted (Justice Mode) | Uncharted (Creativity Mode) |
|------------------------|----------------------------|
| Structure exists | No structure for this |
| Patterns established | No patterns to follow |
| Clear placement available | No rightful place exists |
| Just need to place | Need to build first |

## Step 1: Pioneering Check

### The Core Question
**Am I genuinely venturing into new ground?**

### Verification Questions

```markdown
**New Territory**: [What I'm creating]

**Pioneering Check**:
1. Is this genuinely new for this codebase? [Yes / No]
2. Has this type of structure been built here before? [Yes / No]
3. Am I exploring where this codebase hasn't gone? [Yes / No]
4. Is this territory truly unexplored? [Yes / No]

**Pioneering Indicators**:
- [ ] No existing precedent in codebase
- [ ] New domain or capability
- [ ] First of its kind here
- [ ] Genuinely extending boundaries
```

### Pass/Fail

| Condition | Result |
|-----------|--------|
| Genuinely new territory | **PASS** |
| First of its kind here | **PASS** |
| Similar exists, just missed it | **FAIL** - Use existing |
| Reinventing what exists | **FAIL** - Find and use existing |

## Quick Creativity Verification

```
TERRITORY: Is this uncharted? [Y/N]
  If N → Justice mode (skip creativity checks)
  If Y → Continue

CREATIVITY CHECKS:
1. PIONEERING: Genuinely new ground? [Y/N]
2. PATH-BUILDING: Well-constructed structure? [Y/N]
3. EXTENSION: Coherent growth? [Y/N]
4. VISION: Clear direction? [Y/N]
5. FOUNDATION: Enables future justice? [Y/N]
6. INTEGRATION: Connected to whole? [Y/N]

Any N → Address before proceeding
```

### The Quick Creativity Questions

For rapid verification:

1. **Is this uncharted territory?** (Do I need creativity mode?)
2. **Am I genuinely pioneering?** (Is this truly new?)
3. **Is the path well-built?** (Can others follow?)
4. **Does this connect coherently?** (Extension, not island?)
5. **Do I know where this leads?** (Vision clear?)
6. **Will future justice be possible?** (Foundation solid?)
7. **Is it part of the whole?** (Integrated?)

## The Stagnation Signal

### When Creativity Verification Is Needed

**Stagnation signals that creativity verification should be engaged.**

```
Signs creativity mode is needed:
- "There's no place for this" → Territory uncharted
- "We can't do this with current structure" → Path missing
- "This doesn't fit our patterns" → Extension needed
- "We keep working around this" → Foundation missing
```

### Response to Stagnation

```
Wrong response:
  Stagnation → Force into existing → Hack → Technical debt

Right response:
  Stagnation → Recognize uncharted territory → Activate creativity mode → Build path
```

## When Creativity Verification Fails

### If Pioneering Fails
```
Not actually new territory.

Action:
1. Look for existing patterns
2. Find existing structure
3. Use existing paths
4. Switch to Justice mode
```

### If Path-Building Fails
```
Path is not well-constructed.

Action:
1. Clarify the structure
2. Make it followable
3. Ensure sustainability
4. Strengthen the construction
```

### If Extension Fails
```
New territory is disconnected.

Action:
1. Build bridges to existing
2. Align with architecture
3. Connect to the whole
4. Make extension coherent
```

### If Vision Fails
```
Building blindly without direction.

Action:
1. Clarify the purpose
2. Define where this leads
3. Understand what it enables
4. Have clear vision before building
```

### If Foundation Fails
```
Not enabling future work.

Action:
1. Build for the future, not just now
2. Establish followable patterns
3. Create solid, not fragile foundation
4. Enable future justice
```

### If Integration Fails
```
Creating isolated islands.

Action:
1. Build connections to existing
2. Create bridges
3. Ensure architectural coherence
4. Make new part of the whole
```

## Creativity Verification Summary

### The Core Question
**Am I building a path to uncharted territory that enables future justice?**

### The Verification Chain
0. **TERRITORY**: Charted or uncharted? (Determines mode)
1. **PIONEERING**: Genuinely new ground?
2. **PATH-BUILDING**: Well-constructed structure?
3. **EXTENSION**: Coherent growth?
4. **VISION**: Clear direction?
5. **FOUNDATION**: Future justice enabled?
6. **INTEGRATION**: Connected to whole?

### The Rule
**When territory is uncharted, build the path before placing.**

A beautiful, just solution in uncharted territory requires the path to be built first.
Build well, connect coherently, enable future justice.

### The Promise
Every creative work will build paths that enable future travelers to achieve justice in territories that were once uncharted.
