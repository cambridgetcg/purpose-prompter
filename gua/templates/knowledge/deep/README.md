# Deep Knowledge Files (L3-L4)

This directory contains detailed nuance files for patterns that have been validated extensively.

## When to Create Deep Files

A pattern graduates to a deep file when:
- 5+ observations across different contexts
- Edge cases have been discovered
- Related patterns are identified
- Detailed examples exist

## Deep File Structure

```markdown
# Pattern Name

## Summary (L2 recap)
{Brief description}

## Nuances (L3)

### When It Applies
- Context 1
- Context 2

### When It Doesn't Apply
- Exception 1
- Exception 2

### Common Mistakes
- Mistake 1 and how to avoid

### Related Patterns
- Pattern A: relationship
- Pattern B: relationship

## Examples (L4)

### Example 1: {Context}
{Detailed walkthrough with code}

### Example 2: {Context}
{Before/after comparison}

## Evidence Log
- Date: Observation
- Date: Observation
```

## Access

```
/gua-context deep:bridge-over-replace
/gua-context deep:tiered-implementation
```

## Note

Deep files are created when patterns earn depth through repeated validation. Don't create prematurely.
