# Knowledge by PP Dimension

This directory contains knowledge organized by Purpose Prompter dimensions.

## Structure

```
by-dimension/
├── truth/           # Verification, accuracy, calibration
├── understanding/   # Mental models, comprehension
├── beauty/          # Elegance, fit, coherence
├── justice/         # Placement, ownership, architecture
└── creativity/      # Path-building, pioneering
```

## File Types per Dimension

Each dimension can contain:
- `patterns.md` - Recurring approaches that work
- `blindspots.md` - Gaps or weaknesses to watch
- `anti-patterns.md` - Approaches that fail
- `techniques.md` - Specific methods or procedures
- `models.md` - Mental frameworks
- `principles.md` - Guiding rules

## Access

```
/gua-context dimension:truth
/gua-context dimension:beauty
/gua-context dimension:creativity
```

## Note

Actual knowledge files are stored at `~/.claude/purpose_prompter/knowledge/by-dimension/` and synced via AWS. This template shows the expected structure.
