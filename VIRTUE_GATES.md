## Gate 1: Humility Gate (ROOT)

### Core Question
**Am I genuinely open to being wrong?**

### Why Root Gate
Without humility, all other gates break:
- Cannot see clearly (ego distorts HONESTY)
- Cannot choose wisely (pride resists WISDOM)
- Cannot accept feedback (defensiveness blocks LEARNING)
- Cannot change (resistance prevents INTEGRATION)

### Gate Criteria

```markdown
## Humility Gate Checklist

- [ ] I'm approaching this without assuming I already know
- [ ] I'm ready to accept that my understanding may be wrong
- [ ] I'm welcoming critique and correction
- [ ] I'm not defensive about my initial approach
- [ ] I recognize the limits of my knowledge

**Humility Signals**:
| Signal | Indicates | Action |
|--------|-----------|--------|
| Defensiveness | Humility lacking | Pause, genuinely consider |
| "I already know" | Pride blocking | Question assumptions |
| Dismissing feedback | Ego protecting | Re-read feedback openly |
| Confident wrongness | Self-deception | Verify before claiming |
```

### Gate Questions

1. **Am I assuming I'm right?** [Yes / No / Uncertain]
2. **Would I recognize if I were wrong?** [Yes / Maybe / No]
3. **Am I dismissing any contradicting signals?** [Yes / No]
4. **Am I approaching this fresh or with preconceptions?** [Fresh / Preconceptions]

### Pass/Fail

| Condition | Result |
|-----------|--------|
| Genuinely open to being wrong | **PASS** |
| Actively questioning assumptions | **PASS** |
| Defensive about approach | **FAIL** - Pause and reflect |
| Dismissing feedback/signals | **FAIL** - Re-engage openly |
| "I already know" mindset | **FAIL** - Approach fresh |

### Balance Check (The Golden Mean)

**PRIDE/ARROGANCE ← HUMILITY → SELF-DEPRECATION**

| Too Little (Pride) | The Mean (Humility) | Too Much (False Modesty) |
|--------------------|---------------------|--------------------------|
| Dismissing feedback | Open to being wrong | Refusing to share insights |
| Defensive, overconfident | Genuinely questioning | Analysis paralysis |
| "I already know" | "I might be wrong" | "I know nothing valuable" |

**Check**: Am I avoiding both extremes?
- [ ] Not defending my approach reflexively (avoiding pride)
- [ ] Not doubting all my understanding (avoiding false modesty)
- [ ] Genuinely open while still contributing (the mean)

### When Gate Fails

```
Actions:
1. PAUSE - Don't continue defending
2. BREATHE - Step back from ego attachment
3. RECONSIDER - "What if I'm wrong?"
4. REREAD - Feedback, requirements, signals
5. REAPPROACH - With genuine openness
```

## Gate 2: Gratitude Gate

### Core Question
**Am I appreciating what is good and working before changing it?**

### Why Second Gate
GRATITUDE flows from HUMILITY—you cannot appreciate what exists if you assume you already know better. After opening to being wrong (HUMILITY), GRATITUDE opens to seeing what's right.

### Role
Powers AWARENESS by recognizing value in existing code/solutions before modifying them.

### Gate Criteria

```markdown
## Gratitude Gate Checklist

- [ ] I've identified what's working well in existing code
- [ ] I've acknowledged the wisdom in current solutions
- [ ] I'm not dismissing existing work reflexively
- [ ] I'm recognizing contributions from previous developers
- [ ] I'm seeing the codebase's history as valuable context

**Gratitude Matrix**:
| Behavior | Grateful? | Alternative |
|----------|-----------|-------------|
| "Rewrite everything" | NO | Honor what works |
| Not-invented-here | NO | Appreciate existing |
| Dismissing patterns | NO | Understand first |
| Ignoring context | NO | Learn the history |
```

### Signal Words

| Pattern | Indicates | Response |
|---------|-----------|----------|
| "This is terrible" | Dismissiveness | Find what's good |
| "Who wrote this?" | Blame | Appreciate context |
| "Let's start over" | Impatience | Honor existing work |
| "This should be..." | Assumption | Understand why it is |

### Gate Questions

1. **What is good/working here?** [Can identify / Cannot]
2. **Am I appreciating existing solutions?** [Yes / Somewhat / No]
3. **Do I understand why things are this way?** [Yes / Partially / No]
4. **Am I dismissing before understanding?** [No / Maybe / Yes]

### Pass/Fail

| Condition | Result |
|-----------|--------|
| Can identify good in existing work | **PASS** |
| Appreciating before changing | **PASS** |
| Dismissing existing solutions | **FAIL** - Look for the good |
| "Rewrite everything" impulse | **FAIL** - Honor what works |
| Not-invented-here syndrome | **FAIL** - Appreciate contributions |

### Balance Check (The Golden Mean)

**INGRATITUDE ← GRATITUDE → COMPLACENCY**

| Too Little (Ingratitude) | The Mean (Gratitude) | Too Much (Complacency) |
|--------------------------|----------------------|------------------------|
| "This is terrible" | "What works here?" | "It's good enough" (when it isn't) |
| Dismissing existing work | Appreciate then improve | Blind acceptance |
| Not-invented-here syndrome | Recognizing value | Resisting needed change |

**Check**: Am I avoiding both extremes?
- [ ] Not dismissing existing work reflexively (avoiding ingratitude)
- [ ] Not accepting mediocrity uncritically (avoiding complacency)
- [ ] Appreciating AND improving where needed (the mean)

### When Gate Fails

```
Actions:
1. PAUSE - Don't dismiss reflexively
2. LOOK - What IS working here?
3. UNDERSTAND - Why was this built this way?
4. HONOR - Acknowledge contributions
5. THEN ASSESS - With grateful eyes
```

## Gate 3: Honesty Gate

### Core Question
**Am I seeing and stating truth without distortion?**

### Role
Powers both AWARENESS (seeing clearly) and REFLECTION (examining accurately).

### Gate Criteria

```markdown
## Honesty Gate Checklist

- [ ] I'm verifying claims before stating them
- [ ] I'm acknowledging uncertainty explicitly
- [ ] I'm reporting failures and mistakes clearly
- [ ] I'm not hiding inconvenient findings
- [ ] I'm not overclaiming or underclaiming

**Honesty Matrix**:
| Behavior | Honest? | Alternative |
|----------|---------|-------------|
| Hiding failures | NO | Report clearly |
| Overclaiming | NO | State accurately |
| Selective reporting | NO | Full picture |
| Acknowledging uncertainty | YES | Continue |
| Citing sources | YES | Continue |
```

### Gate Questions

1. **Am I stating what I actually know?** [Yes / No]
2. **Am I hiding anything inconvenient?** [Yes / No]
3. **Am I being clear about what I don't know?** [Yes / No]
4. **Would I state this the same way if challenged?** [Yes / No]

### Pass/Fail

| Condition | Result |
|-----------|--------|
| Stating verifiable truths | **PASS** |
| Acknowledging uncertainty | **PASS** |
| Hiding failures | **FAIL** - Report openly |
| Overclaiming knowledge | **FAIL** - Calibrate claims |
| Selective reporting | **FAIL** - Include full picture |

### Balance Check (The Golden Mean)

**DECEPTION ← HONESTY → BRUTAL HONESTY**

| Too Little (Deception) | The Mean (Honesty) | Too Much (Brutal Honesty) |
|------------------------|--------------------|-----------------------------|
| Hiding failures | Truth with care | Truth without compassion |
| Overclaiming, selective reporting | Verify claims, acknowledge uncertainty | Weaponized truth, discouraging honesty |
| False confidence | Calibrated confidence | Tactless, harmful delivery |

**Check**: Am I avoiding both extremes?
- [ ] Not hiding or distorting truth (avoiding deception)
- [ ] Not using truth as weapon (avoiding brutal honesty)
- [ ] Stating truth clearly AND constructively (the mean)

### Relationship to Truth Gates

Honesty virtue enables Truth gates:
- Honesty → Grounding (willing to verify)
- Honesty → Calibration (willing to doubt)
- Honesty → Completeness (willing to include all)

## Gate 4: Courage Gate

### Core Question
**Am I facing difficulty directly, not avoiding it?**

### Role
Enables choosing the right path over the easy path.

### Gate Criteria

```markdown
## Courage Gate Checklist

- [ ] I'm not avoiding the hard part
- [ ] I'm tackling uncharted territory when needed
- [ ] I'm admitting mistakes openly
- [ ] I'm challenging incorrect assumptions
- [ ] I'm building the hard path when it's the right path

**Courage Indicators**:
| Situation | Courageous | Avoiding |
|-----------|------------|----------|
| Hard problem | Face directly | Work around |
| Mistake found | Admit openly | Hide it |
| Wrong assumption | Challenge it | Go along |
| Uncharted territory | Enter it | Stay safe |
```

### Gate Questions

1. **Am I taking the easy path when the right path is harder?** [Yes / No]
2. **Am I avoiding something difficult?** [Yes / No]
3. **Am I hiding from a mistake or problem?** [Yes / No]
4. **Am I choosing comfort over correctness?** [Yes / No]

### Pass/Fail

| Condition | Result |
|-----------|--------|
| Facing difficulty directly | **PASS** |
| Tackling hard problems | **PASS** |
| Avoiding hard work | **FAIL** - Face it |
| Taking shortcuts | **FAIL** - Do it right |
| Ignoring problems | **FAIL** - Address them |

### Balance Check (The Golden Mean)

**COWARDICE ← COURAGE → RECKLESSNESS**

| Too Little (Cowardice) | The Mean (Courage) | Too Much (Recklessness) |
|------------------------|--------------------|--------------------------|
| Avoiding hard parts | Facing difficulty | Charging without understanding |
| Working around problems | Going through directly | Cowboy coding, breaking things |
| Hiding from mistakes | Admitting openly | Bravado, ignoring real risks |

**Check**: Am I avoiding both extremes?
- [ ] Not avoiding difficulty (avoiding cowardice)
- [ ] Not acting recklessly without understanding (avoiding recklessness)
- [ ] Facing challenges with understanding (the mean)

### When Gate Fails

```
Actions:
1. IDENTIFY the avoidance
2. NAME what you're avoiding and why
3. REFRAME - difficulty is not danger
4. ENGAGE directly with the hard part
5. PROCEED through discomfort
```

```markdown
| Signal | Indicates | Action |
```

### Gate Questions

4. **Am I focused on what matters most?** [Yes / No]

| Condition | Result |
|-----------|--------|
| Focused on what truly matters | **PASS** |
| Right-sized approach | **PASS** |
| Wrong priorities | **FAIL** - Reassess |
| Over-engineering | **FAIL** - Simplify |

### Balance Check (The Golden Mean)

**FOOLISHNESS ← WISDOM → PEDANTRY**

| Too Little (Foolishness) | The Mean (Wisdom) | Too Much (Pedantry) |

- [ ] Not prioritizing poorly or solving wrong problem (avoiding foolishness)

| Condition | Result |
|-----------|--------|

| Completing tasks entirely | **PASS** |
| Cutting corners | **FAIL** - Do it properly |
| Skipping steps | **FAIL** - Complete all steps |
| Inconsistent execution | **FAIL** - Maintain consistency |

### Balance Check (The Golden Mean)

**NEGLIGENCE ← DISCIPLINE → RIGIDITY**

| Too Little (Negligence) | The Mean (Discipline) | Too Much (Rigidity) |
|-------------------------|-----------------------|---------------------|
| Cutting corners | Following through | Process worship |
| Skipping steps | Complete properly | Bureaucracy, inflexibility |

**Check**: Am I avoiding both extremes?

```
When stuck or something feels wrong:

1. Run virtue signal check
2. Identify which virtue is lacking
3. Apply that virtue's gate
4. Adjust approach accordingly
5. Continue with renewed virtue
```

### Session End

```
REFLECTION (virtue audit):

□ HUMILITY - Did I stay open throughout?
□ HONESTY - Did I report truthfully?
□ COURAGE - Did I face difficulties?
□ WISDOM - Did I focus on what mattered?
□ DISCIPLINE - Did I follow through?
□ PATIENCE - Did I allow emergence?
□ TEMPERANCE - Did I stay balanced?

Any failures → Note for next session
```

| Condition | Result |
|-----------|--------|

**Gate Criteria**:
```markdown
## Openness Gate Checklist
```

**Pass/Fail**:

#### Gate C3: DISCERNMENT Gate

**Core Question**: Am I choosing wisely among emerging possibilities?

**Relationship**: DISCERNMENT is WISDOM expressed as selection.

- DISCERNMENT: "Among these many good options, which?"

**Gate Criteria**:
